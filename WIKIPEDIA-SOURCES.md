# Wikipedia sources

The track “Cities, countries, rivers” (German: „Stadt, Land, Fluss“) contains excerpts from Wikipedia articles.
The excerpts are licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Authors: the contributors of each article, see the page history behind each link.

Changes made: only the introduction (for very short introductions also paragraphs from the article body) is used; texts were shortened to about 1,500 characters; pronunciation and foreign-language name brackets, footnote markers and a few leftover fragments were removed; links to other notes of the track were set by Vault Race.

Each link points to the exact article version that was used.
